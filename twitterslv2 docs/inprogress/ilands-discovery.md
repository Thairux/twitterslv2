## PHASE 2 — External research (Threads / X / iLands)

### (a) Threads by Meta

- **Information architecture:** Feed (For You / Following), Search, Post composer (+), Activity (notifications), Profile. No public DM inbox historically — messaging routed through Instagram; standalone Threads DM inbox rolled out globally after testing (message icon in lower bar, text/images/links/GIFs, conversation management). Sources: https://momentumhive.app/blog/threads-dms-2026 · https://www.lifewire.com/meta-tests-threads-dm-feature-11752492 · https://storyy.com/insights/threads-launches-dm-inbox-as-app-pulls-away-from-instagram
- **Thread/comment nesting UX:** flat-ish reply chains under a post with reply management API (hide replies, reply approvals, filter activity feed to replies from followed profiles). Sources: https://developers.facebook.com/documentation/threads/reply-management/ · https://www.androidcentral.com/apps-software/meta/metas-threads-ups-its-game-with-new-controls-to-keep-trolls-at-bay
- **Follow/follower management:** follower-only replies, restricted profiles, mute / restrict / block / hide four-tier control (restrict = invisible soft-limit vs block = hard cut), quote-post limits. Sources: https://www.joltsage.com/blog/restrict-vs-block-on-threads-mute-hide-and-when-to-use-each · https://about.fb.com/news/2025/03/new-threads-features-more-personalized-experience-you-control/
- **Reply/quote controls:** per-post `reply_control` = `everyone` | `accounts_you_follow` | `mentioned_only`; quote gating; changeable after posting (unless federated). Sources: https://www.facebook.com/help/instagram/7690343751001341/ · https://www.facebook.com/help/instagram/771310471063900/ · https://developers.secure.facebook.com/docs/threads/reply-management
- **Notifications:** likes, replies, reposts, quotes, follows — split by followers/non-followers in Insights; profile Insights show totals. No "who viewed without engaging" and no saves tracking. Sources: https://postory.io/blog/threads-analytics · https://replia.net/blog/how-to-use-threads-analytics.html · https://techwiser.com/threads-rolls-out-analytics-to-all-users-heres-what-you-can-track/
- **Search:** filters for profiles-only / posts-only / media types. Source: https://wisechecker.com/how-to-use-search-filters-threads-results/
- **Profiles:** follower counts, post views, likes/replies/reposts/quotes breakdowns; analytics lack historical trends/export/comparison (3rd-party dashboards fill the gap). Sources: https://sproutsocial.com/insights/threads-metrics/ · https://replia.net/blog/threads-analytics-dashboard-guide.html
- **Media/polls/drafts:** Threads added polls, GIFs, voice notes over 2024-26; edit window is short (5 min) and repost/quote UNDO windows similar; drafts exist in composer. Edit-window claim is widely documented in release coverage — verify at implementation time against current Help Center.
- **What to steal:** per-post reply audience selector (maps to `reply_control` enum on posts), quote gating, hide-reply (not delete), media-type search filter, follower/non-follower notification split.
