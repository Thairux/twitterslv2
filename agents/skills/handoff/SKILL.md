# handoff — Session Continuity

Load at session start (after aboutrepo) and before stopping.

## Rules
- Work notes live in `twitterslv2 docs/inprogress/session-{date}-{id}.md`:
  done / in-progress / blocked / next-files.
- `twitterslv2 docs/sprint-history/sprint-{N}.md` is updated per sprint, never rewritten
  wholesale — append corrections with dates.
- HANDOFF.md (root) always points at the current sprint + next files.
- Keep notes compact: paths + decisions + open questions, no prose dumps.
